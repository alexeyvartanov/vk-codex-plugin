# ВКонтакте для Codex

Плагин для Codex, который подключает ваше сообщество ВКонтакте через
локальный MCP-сервер. Codex сможет читать сообщения сообщества: кто написал,
о чём, историю переписки, и готовить ответы. Отправлять ответы он может, только
если вы это включите, и каждый раз спрашивает ваше согласие. Посты, комментарии
и любые другие изменения в сообществе сервер не пропускает.

Ключ доступа хранится только на вашем компьютере, в папке `vk-mcp` в домашней
папке. В чат он не попадает, в репозиторий тоже.

## Что нужно

- Codex на компьютере (приложение или CLI), macOS или Windows.
- Ключ доступа сообщества: в сообществе «Управление» → «Работа с API» →
  «Ключи доступа» → «Создать ключ», отметить «Сообщения сообщества».
- Python 3.9 или новее. На Windows установщик поставит его сам, на macOS
  при необходимости выполните `xcode-select --install`.

## Установка

Проще всего попросить Codex сделать всё самому. Скопируйте этот запрос в Codex:

```
Установи мне плагин «ВКонтакте для Codex» из репозитория GitHub alexeyvartanov/vk-codex-plugin.
Сначала добавь этот репозиторий как источник плагинов командой codex plugin marketplace add alexeyvartanov/vk-codex-plugin. Если команда codex недоступна, скажи мне простыми словами, где в приложении добавить источник плагинов, и подожди.
Потом установи из этого источника плагин vk-community-connector. Если установить сам не можешь, скажи, где нажать «Установить».
Если после установки нужно перезапустить Codex, скажи мне об этом.
Когда плагин установлен, запусти его навык подключения ВК и веди меня по шагам. Ключ ВК в чат я не пишу.
Объясняй как человеку, который ничего не понимает в компьютерах: по одному действию за раз.
```

После установки плагина Codex нужно полностью закрыть и открыть снова,
затем написать «Подключи ВК». Дальше: ссылка на сообщество в чат, ключ в
открывшийся файл (Блокнот или TextEdit), «готово», ещё один перезапуск Codex.

Вручную то же самое: `codex plugin marketplace add alexeyvartanov/vk-codex-plugin`,
затем установить плагин «ВКонтакте для Codex» в разделе плагинов.

Проверено: macOS. Windows проверяется.

## Что умеет

С ключом сообщества: диалоги и история сообщений сообщества, поиск по
сообщениям, участники сообщества, заказы магазина. Стена, обсуждения и
статистика ключу сообщества ВКонтакте не отдаёт.

Инструменты MCP: `vk_list_connections`, `vk_check_connection`,
`vk_get_capabilities`, `vk_search_methods`, `vk_method_info`,
`vk_call_read`, `vk_call` (только `messages.send` и `messages.markAsRead`,
если отправка включена: «Разреши отправлять в ВК» / «Запрети отправку в ВК»).

## Где что лежит после установки

- `~/vk-mcp/src/vk_mcp_server.py` — сервер (только стандартная библиотека Python);
- `~/vk-mcp/schema/catalog.json` — 569 методов из официальной схемы VK API;
- `~/vk-mcp/config/connections.json` — подключённые сообщества;
- `~/vk-mcp/config/tokens/` — ключи, по одному файлу на сообщество;
- `~/.codex/config.toml` — блок `[mcp_servers.vk]`, рядом копия до изменения.

Чтобы отключить: удалите блок `[mcp_servers.vk]` из `~/.codex/config.toml`
и папку `~/vk-mcp`, а ключ удалите в настройках сообщества.
